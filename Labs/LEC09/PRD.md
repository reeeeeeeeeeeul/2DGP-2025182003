# Sonic Animation Viewer PRD

## 1. 문서 개요

- 문서 목적: `PRE-PRD.md`의 아이디어를 실제 구현 가능한 개발 요구사항으로 구체화한다.
- 제품명: Sonic Animation Viewer
- 대상 경로: `Labs/LEC09`
- 개발 언어: Python
- 사용 라이브러리: `pico2d`
- 실행 파일: `sonic_animation_viewer.py`
- 입력 리소스: `sonic-sprite.png`
- 구현 단위: 실행 파일 1개. 외부 설정 파일, 별도 모듈, 추가 에셋은 사용하지 않는다.

## 2. 제품 목표

소닉 스프라이트 시트에 포함된 모든 애니메이션 동작을 순서대로 재생하고, 각 동작을 사용자가 식별할 수 있는 크기로 보여주는 학습용 애니메이션 뷰어를 만든다.

뷰어는 한 동작을 5회 반복한 뒤 1초 동안 정지하고 다음 동작으로 넘어간다. 마지막 동작까지 재생하면 첫 동작부터 같은 순서를 무한 반복한다.

## 3. 범위

### 포함 범위

- 스프라이트 시트 열기 및 화면 표시
- 스프라이트 시트에서 동작별 프레임 영역 정의
- 동작별 프레임 애니메이션 재생
- 동작마다 5회 반복
- 동작 전환 시 1초 정지
- 마지막 동작 이후 첫 동작으로 순환
- 검은 배경 또는 이미지가 잘 보이는 고대비 배경
- 원본보다 충분히 큰 확대 배율로 캐릭터 표시
- 창 종료 이벤트 처리

### 제외 범위

- 키보드·마우스로 동작을 선택하는 편집 기능
- 스프라이트 시트 자동 분할 도구
- 애니메이션 저장 및 내보내기
- 사운드, 음악, 게임 플레이, 충돌 판정
- 여러 캐릭터 또는 여러 이미지 파일 지원
- 네트워크 기능 및 외부 데이터 로딩

## 4. 사용자 시나리오

1. 사용자가 `sonic_animation_viewer.py`를 실행한다.
2. 뷰어 창이 열리고 스프라이트가 충분히 확대되어 표시된다.
3. 첫 번째 동작의 프레임이 순서대로 재생된다.
4. 첫 번째 동작이 정확히 5회 재생되면 1초 동안 화면이 유지된다.
5. 다음 동작이 같은 방식으로 재생된다.
6. 걷기·달리기·뒤로 이동 동작은 애니메이션 재생과 함께 캐릭터 위치도 이동한다.
7. 이동 중 캐릭터가 화면 한쪽 경계를 넘으면 반대쪽에서 이어서 나타난다.
8. 모든 동작이 끝나면 별도 종료 없이 첫 번째 동작부터 다시 시작한다.
9. 사용자가 창 닫기 버튼을 누르면 정상적으로 종료된다.

## 5. 기능 요구사항

### FR-01. 초기화

- 프로그램은 `pico2d`를 초기화하고 뷰어 창을 생성해야 한다.
- 프로그램 시작 시 `sonic-sprite.png`를 한 번만 로드해야 한다.
- 이미지 로드 실패 시 원인을 확인할 수 있는 오류를 출력하고 비정상적인 프레임 접근을 수행하지 않아야 한다.
- 이미지 경로는 실행 위치가 달라도 `sonic_animation_viewer.py` 기준으로 찾을 수 있도록 구성한다.

### FR-02. 애니메이션 데이터

- 모든 동작은 이름, 프레임 목록, 프레임 간 재생 시간, 표시 순서를 갖는 데이터로 정의한다.
- 프레임은 스프라이트 시트의 사각형 좌표로 표현한다.
- 동작 목록은 코드에서 한 곳에 모아 수정할 수 있어야 한다.
- 스프라이트 시트의 제목, 설명 문구, 제작자 문구 등 캐릭터가 아닌 영역은 애니메이션 프레임에 포함하지 않는다.
- 프레임 좌표와 동작 분류는 실제 이미지 분석 결과를 기준으로 확정한다.

### FR-03. 프레임 재생

- 현재 동작의 프레임을 정해진 순서로 표시한다.
- 프레임 전환은 고정 지연이 아니라 경과 시간 기반으로 처리한다.
- 프레임 재생 속도는 동작별로 조정할 수 있어야 한다.
- 한 프레임을 표시하는 동안 창 이벤트 처리를 계속 수행해야 한다.

### FR-04. 반복 횟수

- 각 동작은 5회 재생해야 한다.
- 한 동작의 마지막 프레임이 끝나면 해당 동작의 반복 횟수를 1회 증가시킨다.
- 5회가 끝나기 전에는 다음 동작으로 이동하지 않는다.
- 반복 횟수는 동작이 시작될 때 0으로 초기화한다.

### FR-05. 동작 전환 대기

- 동작을 5회 재생한 직후 다음 동작으로 바로 전환하지 않고 1초 대기한다.
- 대기 중에는 직전 동작의 마지막 프레임을 유지한다.
- 대기 시간은 누적 경과 시간으로 측정한다.
- 대기 시간이 끝나면 반복 횟수를 초기화하고 다음 동작의 첫 프레임부터 재생한다.

### FR-06. 전체 순환

- 마지막 동작의 5회 재생과 1초 대기가 끝나면 첫 동작으로 이동한다.
- 전체 재생 횟수에는 제한을 두지 않는다.
- 동작 인덱스가 마지막 인덱스를 넘지 않도록 순환 처리한다.

### FR-07. 화면 및 렌더링

- 캐릭터가 배경과 구분되도록 고대비 배경을 사용한다.
- 프레임의 원본 비율을 유지한 채 확대한다.
- 확대 배율은 캐릭터가 창에서 충분히 크게 보이는 값으로 설정한다.
- 창 크기와 렌더링 위치는 코드의 상수 또는 설정값으로 쉽게 조정할 수 있어야 한다.
- 프레임이 확대될 때 흐릿함을 줄이기 위해 `pico2d`의 이미지 그리기 방식과 배율을 일관되게 사용한다.
- 스프라이트 시트 전체가 아니라 현재 프레임만 화면에 그린다.

### FR-08. 종료 처리

- 창 닫기 이벤트를 감지하면 메인 루프를 종료한다.
- 종료 시 로드한 이미지와 `pico2d` 창을 정상적으로 정리한다.
- 애니메이션 대기 중에도 종료 이벤트에 응답해야 한다.

### FR-09. 이동 애니메이션

- 이동이 포함된 동작은 이름, 프레임 목록, 프레임 시간과 함께 초당 이동 속도를 가져야 한다.
- `walk` 동작은 양의 이동 속도로 캐릭터를 오른쪽으로 이동시킨다.
- `run` 동작은 `walk`보다 빠른 양의 이동 속도로 캐릭터를 오른쪽으로 이동시킨다.
- `back` 동작은 음의 이동 속도로 캐릭터를 왼쪽으로 이동시킨다.
- `jump`, `roll`, `spin`, `crouch`, `fall`, `idle` 동작의 기본 이동 속도는 0으로 한다.
- 위치 이동량은 프레임 수가 아니라 `이동 속도 x 경과 시간`으로 계산한다.
- `PLAYING` 상태에서만 위치를 갱신하며, `WAITING` 상태에서는 마지막 위치를 유지한다.
- 캐릭터가 화면 오른쪽 경계를 완전히 벗어나면 왼쪽 바깥에서 다시 진입한다.
- 캐릭터가 화면 왼쪽 경계를 완전히 벗어나면 오른쪽 바깥에서 다시 진입한다.

## 6. 상태 및 전환 규칙

뷰어는 다음 상태를 사용한다.

- `PLAYING`: 현재 동작의 프레임을 재생하는 상태
- `WAITING`: 현재 동작을 5회 재생한 후 1초 대기하는 상태
- `CLOSED`: 종료 이벤트를 받아 루프를 끝낸 상태

전환 규칙:

1. 시작 시 첫 동작의 첫 프레임과 함께 `PLAYING` 상태로 진입한다.
2. 현재 동작의 마지막 프레임이 끝나면 해당 동작의 반복 횟수를 증가시킨다.
3. 반복 횟수가 5회 미만이면 해당 동작의 첫 프레임으로 돌아가 `PLAYING`을 유지한다.
4. 반복 횟수가 5회이면 `WAITING`으로 전환하고 대기 타이머를 시작한다.
5. 1초가 지나면 다음 동작을 선택하고 반복 횟수를 0으로 초기화한 뒤 `PLAYING`으로 전환한다.
6. 마지막 동작 이후에는 첫 동작을 선택한다.
7. 종료 이벤트가 발생하면 어떤 상태에서도 `CLOSED`로 전환한다.

## 7. 기술 요구사항

- 메인 루프는 `pico2d`의 이벤트 처리, 시간 갱신, 화면 지우기, 그리기, 화면 갱신 순서를 지켜야 한다.
- 실제 경과 시간은 `pico2d.get_time()` 또는 동등한 시간 함수를 사용해 계산한다.
- `frame_index`, `action_index`, `repeat_count`, `state`, `elapsed_time`의 역할을 분리한다.
- 프레임 전환과 동작 전환 조건은 메인 루프 안에서 확인할 수 있도록 단순하게 유지한다.
- 한 파일 안에서도 이미지 로드, 데이터 정의, 상태 갱신, 렌더링, 종료 처리를 함수 단위로 구분한다.
- 사용하지 않는 라이브러리와 디버그 출력은 최종 코드에서 제거한다.
- 코드 실행 시 현재 작업 디렉터리에 의존하지 않도록 리소스 경로를 처리한다.

## 8. 품질 및 사용성 요구사항

- 실행 직후 검은 화면만 보이거나 이미지 일부가 잘리지 않아야 한다.
- 캐릭터가 창 경계 밖으로 나가지 않아야 한다.
- 이동 동작에서 캐릭터 위치가 프레임 재생 속도에 따라 불규칙하게 변하지 않아야 한다.
- 대기 상태에서 캐릭터가 이동하지 않아야 한다.
- 화면 경계 순환 시 캐릭터가 갑자기 화면 중앙으로 순간이동하지 않아야 한다.
- 애니메이션이 멈추거나 지나치게 빠르게 재생되지 않아야 한다.
- 동작 전환 시 프레임 인덱스가 이전 동작에서 이어지지 않아야 한다.
- 1초 대기 시간이 프레임 재생 시간에 섞이지 않아야 한다.
- 반복 횟수가 5회를 초과하거나 5회보다 적게 동작이 바뀌지 않아야 한다.
- 장시간 실행해도 동작 인덱스와 반복 횟수가 잘못 누적되지 않아야 한다.

- 각 동작이 정확히 5회 반복된다.
- 동작과 동작 사이에 1초 대기가 발생한다.
- 모든 동작 재생 후 처음부터 자동으로 반복된다.

- 화면 경계를 벗어난 캐릭터가 반대편에서 계속 이동한다.
- 캐릭터가 충분히 확대되어 식별 가능하다.
- 창 닫기 버튼으로 정상 종료된다.
- 실행 위치가 `Labs/LEC09`이 아니어도 이미지 경로가 정상적으로 처리된다.
- 코드가 단일 Python 파일 조건을 지킨다.

## 10. 단계별 개발 계획

각 단계는 동작 가능한 작은 변경으로 완료하고, 단계가 끝날 때마다 별도 커밋할 수 있도록 한다.

1. `Labs/LEC09` 작업 브랜치를 확인하고 기존 파일 상태를 점검한다.
2. `pico2d` 설치 및 실행 환경을 확인한다.
3. 빈 `sonic_animation_viewer.py` 파일과 기본 진입점을 만든다.
4. `pico2d` 창을 열고 닫는 최소 프로그램을 구현한다.
5. 프로그램 종료 이벤트를 처리한다.
6. `sonic-sprite.png`를 로드하고 로드 실패를 확인한다.
7. 스프라이트 시트 전체를 임시로 화면에 표시해 이미지 좌표와 크기를 검증한다.
8. 화면 배경색과 창 크기를 정한다.
9. 첫 번째 캐릭터 프레임의 좌표를 정의한다.
10. 현재 프레임 하나를 확대해 화면 중앙에 표시한다.
11. 첫 번째 동작의 전체 프레임 목록을 정의한다.
12. 경과 시간으로 프레임을 순서대로 변경한다.
13. 첫 번째 동작이 한 번 끝났을 때 첫 프레임으로 돌아가도록 한다.
14. 현재 동작의 반복 횟수와 반복 조건을 추가한다.
15. 모든 동작 데이터를 이름과 프레임 목록으로 정리한다.
16. 동작 인덱스를 사용해 다음 동작으로 전환한다.
17. 동작 전환 시 프레임 인덱스와 반복 횟수를 초기화한다.
18. 5회 재생 후 `WAITING` 상태를 추가한다.
19. `WAITING` 상태에서 직전 프레임을 유지한다.
20. `WAITING` 상태의 1초 타이머를 구현한다.
21. 마지막 동작 뒤 첫 동작으로 순환하도록 한다.
22. 모든 동작의 실제 스프라이트 좌표와 프레임 순서를 채운다.
23. 동작별 프레임 속도와 확대 배율을 조정한다.
24. 실행 위치를 바꾸어도 리소스가 로드되는지 검증한다.
25. 장시간 반복 실행으로 프레임, 반복 횟수, 동작 전환을 검증한다.
26. 코드 정리, 불필요한 출력 제거, 주석 및 함수 이름 점검을 수행한다.
27. 완료 기준을 수동 검증하고 최종 커밋을 준비한다.
28. 걷기·달리기·뒤로 이동 동작의 이동 속도를 정의한다.
29. 경과 시간 기반 캐릭터 위치 갱신 함수를 구현한다.
30. 이동 위치를 렌더링 좌표에 연결한다.
31. 화면 경계 통과 시 반대편으로 순환하는 동작을 구현한다.
32. 이동 중·대기 중 위치 변화를 각각 검증한다.
33. 이동 기능을 포함한 완료 기준과 검증 결과를 문서에 반영한다.

## 11. 검증 시나리오

### 정상 재생

- 프로그램 실행 후 캐릭터가 보이는지 확인한다.
- 현재 동작의 프레임이 순서대로 바뀌는지 확인한다.
- 동작 하나가 5회 재생되는지 확인한다.
- 5회 재생 후 마지막 프레임이 1초 유지되는지 확인한다.
- 다음 동작이 첫 프레임부터 시작하는지 확인한다.
- 마지막 동작 후 첫 동작으로 이어지는지 확인한다.

### 이동 재생

- `walk` 재생 중 캐릭터의 x좌표가 시간에 따라 증가하는지 확인한다.
- `run`의 초당 이동량이 `walk`보다 큰지 확인한다.
- `back` 재생 중 캐릭터의 x좌표가 감소하는지 확인한다.
- `WAITING` 상태에서 x좌표가 유지되는지 확인한다.
- 오른쪽과 왼쪽 경계를 각각 통과했을 때 반대편으로 순환하는지 확인한다.

### 종료 및 경로

- `PLAYING` 상태에서 창을 닫아 정상 종료되는지 확인한다.
- `WAITING` 상태에서 창을 닫아 정상 종료되는지 확인한다.
- `Labs/LEC09`와 프로젝트 루트에서 각각 실행해 이미지가 로드되는지 확인한다.

### 시각 품질

- 캐릭터가 배경과 명확히 구분되는지 확인한다.
- 확대된 이미지의 비율이 유지되는지 확인한다.
- 캐릭터가 화면 밖으로 잘리지 않는지 확인한다.
- 스프라이트 시트의 글자나 빈 영역이 프레임으로 표시되지 않는지 확인한다.

- 동작별 재생 순서 편집
